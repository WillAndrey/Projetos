#Projeto Webtracker

Sou corredor amador e criei esse scraper para pegar informações de preço de um tênis da adidas, (pode ser usado para qualquer outro tipo de produto) e verificar quando o preço estiver abaixo de determinado valor durante um determinado período de tempo e assim me notificar via e-mail quando esse valor estiver abaixo do valor esperado.

🚀 Tecnologias utilizadas

+ Axios – para realizar requisições HTTP a páginas e APIs
+ Cheerio – para fazer web scraping, permitindo selecionar e extrair elementos do HTML
+ dotenv – para gerenciar variáveis de ambiente de forma segura
+ Nodemailer – para enviar e-mails automaticamente com os dados coletados
